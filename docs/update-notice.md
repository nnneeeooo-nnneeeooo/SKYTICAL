# 雙語近期更新通知

中英文公開頁面共用 templates/_update_notice.html、static/update-notice.css 及 static/update-notice.js。原生 dialog 覆蓋在目前頁面上；右上角叉叉、繼續閱讀及 Escape 都只關閉浮窗。內容可在浮窗內捲動，關閉鍵和底部按鈕固定；翼標共用團隊頁的圖像與動畫 CSS，遵守減少動態設定。

## 時間規則

- 以實際顯示時刻起算10,800,000毫秒，未滿三小時不再顯示，滿三小時後下次開頁才顯示。
- 關閉浮窗與更新網站內容不重設計時，不在讀者停留期間計時彈出。
- 中英文、首頁和內頁共用同來源 localStorage key：skytical:update-notice:last-shown:v1。
- 支援 Web Locks 的瀏覽器以來源層級鎖避免多分頁同時顯示；其他瀏覽器使用同步讀寫。
- 原本在頁面快取中的內容重新開啟時也會檢查。其他 dialog 開啟時先等待其關閉。
- 儲存被封鎖時保留目前頁面的記憶，不阻擋閱讀；跨頁／跨裝置／清除網站資料後無法維持該瀏覽器的間隔。

## 內容維護

pipeline/update_notice.py 在每次建站時讀取 config/changelog.json，整理近十四天內、日期有效且具中英文內容的紀錄。紀錄可附有效的提交 SHA，無對應提交的公告用 `commit: null`。產生過程完全離線，不呼叫模型或 GitHub API，也不依賴 checkout 是否具有完整 Git 歷史。

維護公告時，逐項判斷讀者實際會感受到什麼差異、是否需要知道或採取行動，以及影響是否已由正式站或可靠紀錄證實。優先刊登新功能、重大介面或操作變更、影響讀者的服務中斷與恢復，以及需要主動通知的重大更正。敘述以讀者能做什麼、會遇到什麼或需要留意什麼為主。

例行補稿、補齊新聞照片、單篇換圖、文字微調與內部維護，沿原有文章、編輯或 Git 流程處理。有符合刊登門檻的新項目時，再更新讀者公告及對應的雙語更新紀錄。只有例行作業時，保留現有公告內容與日期。

符合門檻的功能更新獨立呈現；同主題只採最新說明，避免舊規則與新規則並列。符合門檻的小調整合併一項；合併項目使用最近更新日期，前端只顯示MM/DD。模型升級須同時符合更新紀錄及目前實際設定，相關能力與補查來源的描述也須有紀錄佐證。其他未識別的新功能沿用原有雙語文字，不自行杜撰效能提升。

符合刊登門檻的紀錄可用選填 notice.importance 設為 major 或 minor，調整是否獨立呈現；讀者畫面隱藏分類標籤。通知會隨建站更新。

`notice.highlight: true` 會使用重要公告配色。可用 `notice.title.zh` 與 `notice.title.en` 指定雙語標題。若內文第一行與指定標題相同，浮窗只顯示一次標題。`notice.link` 的 `label` 與 HTTPS `href` 可將內文第一次出現的指定文字轉成連結。

config/station-note.json 分別維護 messages.zh、messages.en，enabled 可隱藏留言。來信地址沿用既有團隊頁公開地址，瀏覽器以安全DOM建立mailto連結，不插入原始HTML。文字中的neo使用翼標紅、橙、金色。static/neo-life.jpg 是使用者核准照片的臉部裁切，約30KB；不發布原始整張照片或本機Demo。

## 檢查

- python tests/test_update_notice.py：雙語對應、來源門檻、同主題去重、日期及正式版型。
- node tests/test_update_notice.js：三小時前1毫秒、三小時整、無效及未來時間戳記。
- python tests/browser/notice_check.py：Chromium實際操作，涵蓋中英文320／390／768／1440px、跨語言／分頁間隔、關閉、捲動、照片、來信連結及減少動態。
- update-notice-browser workflow 會保存畫面與檢查結果；上線後可手動帶入 https://skytical.tech 驗證正式站。

## 手動開啟與主題

頂列公告按鈕可隨時重看，不受三小時間隔限制，也不改寫自動提醒時間。手機版與社群連結一起位於更多選單。點擊或觸碰遮罩會關閉公告；從內文拖曳到外面不會誤關，關閉後焦點返回原按鈕或手機選單。內容區保留原生捲動並隱藏捲動軸。

header.css共用中英文與裝置尺寸，8bit使用相同的新版手機／平板配置，保留像素字體、方形控制項與深藍金色主題。

## 手機展開與留言照片

手機頂部直接顯示公告及社群按鈕、語言與主題控制；所有導覽連結展開為兩列，沒有更多選單按鈕。reader-layout維持桌機／平板原本行為及跨尺寸還原。

留言照片使用neo-life-expanded.jpg，僅發布取景範圍，不發布完整原圖。先量測原有留言區的尺寸，再於相同面積內放大照片框；文字尺寸維持不變，手機行距微調至1.7，所有內容須保持於邊界內。開啟、尺寸或字體改變時重新計算。
