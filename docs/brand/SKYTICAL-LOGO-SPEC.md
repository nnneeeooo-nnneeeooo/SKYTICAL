# SKYTICAL Logo 規格與重現方式

本文件定義 SKYTICAL 網站的唯一 Logo 母版、色票、裁切方式與衍生資產。未來更新 Logo 時，必須以 `SKYTICAL-master.svg` 為唯一來源，禁止重新描圖、替換字型或手動調整各個輸出檔。

## 品牌內容

- 主字標：`SKYTICΛL`
- 自訂字元：倒 V／希臘 Lambda `Λ`，不可改成一般字母 `A`
- 標語：`SKYLINE TO AVIATION NEWS`
- 構圖：左側三層掠翼，右側主字標，標語置於主字標下方
- 背景：正式 Logo 必須透明；`#F3F2F2` 僅可用於預覽與社群分享圖

橫式 Logo 與翼標的產生規則：

1. 從母版移除 `#FFFFFF` 與 `#F3F2F2` 的兩個全畫布 `<rect>`，使背景透明。
2. 橫式 Logo 的翼形遮罩與彩色圖層均使用 `matrix(0.95, 0, 0, 0.95, 254.925, 630.3)`；對應裁切路徑為 `M 254.925 630.3 L 522.825 630.3 L 522.825 869.7 L 254.925 869.7 Z`。2026-10-19 依使用者要求，將翼標向右移 `17px`、向上移 `15px`，縮短字標間距，讓翼標最上方紅色邊緣與主字標頂端水平對齊。縮放比例維持不變，不改變圖示本身的長寬比、造型或色彩。
   獨立翼標 `skytical-mark.svg` 沒有相鄰文字，沿用 `matrix(0.95, 0, 0, 0.95, 237.925, 645.3)` 與裁切路徑 `M 237.925 645.3 L 505.825 645.3 L 505.825 884.7 L 237.925 884.7 Z`，保持其獨立圖示置中方式。
3. 依上表修改根 `<svg>` 的輸出尺寸與 `viewBox`；主字標與標語的路徑、位置及比例不得變更。

以 `1000 × 220` 橫式 Logo、半透明邊緣不計入時驗證，翼形可視範圍為 `x=38–234`、`y=22–159`；主字標範圍為 `y=22–127`。翼標最上方紅色邊緣與主字標頂端同為 `y=22`。翼形與主字標的水平留白由約 `39px` 縮短為 `22px`；標語仍位於原座標。以紅色翼標頂端與主字標頂端對齊，不使用垂直中心對齊。

社群分享圖使用 `#F3F2F2` 的 `1200 × 630` 畫布，將透明橫式 Logo 以 `1000 × 220` 尺寸置於 `(100, 205)`。

SVG 與分享圖可由母版重建：

```powershell
python docs/brand/generate_classic_logo.py
# 同時輸出分享圖（需要既有 Node.js 與 Sharp 工具環境）
python docs/brand/generate_classic_logo.py --social
```

若 Sharp 已安裝於其他工具環境，可用 `--sharp-module <套件絕對路徑>` 指定，不需要新增網站執行時依賴。上列 SVG 雜湊以 Git 的 LF 換行格式計算。

## 驗收標準

- `SKYTICΛL` 與標語拼字完全一致，`Λ` 不得變成 `A`。
- 三層機翼順序固定為紅、橘、金；不得反轉、混色或套用漸層、陰影與濾鏡。
- 橫式 Logo 的紅色翼標頂端必須與主字標頂端水平對齊，誤差不得超過 `1px`；標語維持原座標。
- 頁首、頁尾、favicon、結構化資料與社群分享圖均來自同一母版。
- 橫式與翼標 SVG 背景透明，不含白色或灰色背景矩形。
- 桌機與手機版均維持原有容器尺寸，不因母版的方形畫布產生額外空白。
- 母版 SHA-256 必須與本文件相同；若不同，應視為新的品牌版本並同步更新本文件、衍生資產與快取版本。

## 8-bit 主題的獨立衍生資產

2026-10-19 依使用者要求新增像素風版本，供隱藏主題與預覽使用。這是明確授權的像素化衍生版本，不替換上述正式母版或已核准資產；前述禁止重新取樣與替換字型的規則仍適用於正式 Logo 的一般輸出。

像素版保留紅、橘、金三層掠翼、`SKYTICΛL` 的倒 V／Lambda（無橫槓），以及完整標語。檔案、重建指令與使用限制見 [SKYTICAL-8BIT-LOGO.md](SKYTICAL-8BIT-LOGO.md)。於頁尾「資料來源」點擊 `8-bit` 解鎖並重新整理後，即可切換像素主題。
