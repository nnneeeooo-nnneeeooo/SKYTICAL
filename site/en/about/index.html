Methodology

Methodology

AVWIRE is a fully automated aviation news aggregator: every hour it fetches trusted sources such as FAA, ICAO, IATA and Reuters, writes the stories automatically, and credits every original source at the end of each article. No human editing; sources always prevail.

Automated pipeline

01 GitHub Actions triggers the workflow at the top of every hour
02 Fetch RSS and open APIs from FAA / ICAO / IATA / Reuters and more
03 De-duplicate, merge across sources, and draft stories with a language model
04 Publish to GitHub Pages with original source links appended to every article

Writing & attribution

Each story is written by a language model from multiple original sources: it aggregates facts only, adds no unsupported inference, and merges duplicate coverage of the same event. The Sources box lists every reference used.

Schedule

GitHub Actions triggers at the top of every hour (cron: 0 * * * *), using free public interfaces only: RSS, open APIs and web pages. A full run takes 3–5 minutes and publishes to GitHub Pages.

Open source

The whole site is open source; the repo layout is below. Inspect the code, file issues, or deploy your own copy.
